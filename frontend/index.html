Do the strings group by themselves?

Each string becomes a feature vector (length, symbol counts, bigram counts, first and last symbol). K-means groups them and PCA flattens the result to two dimensions. Circles are accepted strings, triangles are rejected. If a cluster is mostly one label, the features alone hint at the language.
